# Сканер уязвимостей (SQLi, XSS, LFI, RCE)

Многопоточный сканер для автоматического поиска веб-уязвимостей.  
Поддерживает **SQL-инъекции**, **XSS**, **LFI** и **RCE**.

---

## Возможности

- 🚀 **Многопоточность** — сканирует параметры параллельно (до 10 потоков).
- 🔍 **Автоматический поиск параметров** — извлекает формы (GET/POST) и ссылки с параметрами.
- 🛡️ **4 типа уязвимостей**:
  - SQLi (SQL-инъекции)
  - XSS (межсайтовый скриптинг)
  - LFI (локальное включение файлов)
  - RCE (удалённое выполнение команд)
- 📊 **Генерация отчётов** — сохраняет результаты в JSON и HTML.
- 🎨 **Цветное логирование** — наглядно показывает процесс сканирования.
- ⚙️ **Гибкая настройка** — таймауты, задержки, User-Agent и количество потоков легко меняются в `CONFIG`.

---

## Установка и запуск

### Клонируй репозиторий
```bash
git clone https://github.com/persival-dev/vuln-skaner.git
cd vuln-skaner


## Установи зависимости
pip install -r requirements.txt


Запусти сканер
python scanner_final.py
После запуска введи URL сайта (например, http://testphp.vulnweb.com/artists.php?artist=1 или свой локальный полигон). Сканер сам найдёт параметры и начнёт проверку.


Тестирование
Для безопасного тестирования можно использовать:

Локальный уязвимый сайт — например, DVWA (запускается через Docker или вручную).

Легальные учебные полигоны:

http://testphp.vulnweb.com

http://testasp.vulnweb.com

⚠️ Важно: сканируй только те сайты, на которые у тебя есть разрешение.


Пример работы
На тестовом сайте DVWA сканер нашёл 16 уязвимостей за несколько секунд.
